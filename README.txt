SKY HOP RUN  あそびかた
========================

■ はじめかた
 1. このZIPを右クリック →「すべて展開」
    ※ ZIPを開いたままだと動きません。必ず展開してください
 2. 展開した SKY-HOP-RUN フォルダの index.html をダブルクリック
    （Edge か Chrome で開きます）
 3. インターネットにつないだ状態で遊んでください
    （3D表示の部品をネットから読み込みます）

■ 操作
 WASD / 矢印キー … 移動
 Space            … ジャンプ
 Shift            … ダッシュ
 マウス           … カメラ（画面を1回クリックすると回せます）
 ホイール         … ズーム
 R                … 最初から
 M                … 音 ON/OFF
 H                … 操作説明の表示/非表示

■ ルール
 CPU 5人とレースして、4つのチェックポイントを通ってゴールを目指します。
 落ちてもチェックポイントからやり直せます。

■ 重いとき
 タイトル画面で画質を LOW にしてください。

※ オンライン対戦は専用サーバーが必要なので、このファイルだけでは動きません。
